Linux commands are used to interact with the operating system through the terminal. They help users manage files and directories, install software, monitor system processes, check network connectivity, and manage file permissions.

1) pwd - Displays the current working directory

2) ls - Lists files and directories.

3) ls -l -Displays files with detailed information.

4) ls -a -displays all files with the hidden files.

5) cd folder_name -changes the current directory.

6) cd .. -Moves to parent directory.

7) cd ~ -Moves to the home directory.

8) touch file.text -creates an empty file.

9) mkdir folder -creates a new directory

10) rmdir folder -removes an empty directory.

11) cp file1 file2 -copies a file.

12) cat file.txt -Displays file contents.

13) grep -Searches for files and directories

14) sudo -Executes commands with elevated privilages.

15) mv old.txt new.txt -Moves or renames files and directories.

16) ps -Displays information about running processes.

17) clear – Clears the terminal screen.

18) whoami – Displays the current logged-in username.

19) history – Displays previously executed commands.

20) rm file.txt – Deletes a file.

21) rm -r folder – Deletes a directory and its contents.

22) sudo apt update – Updates the package lists.

23) sudo apt install package_name – Installs a software package.

24) df -h – Displays available disk space.

25) free -h – Displays memory usage.

26) top – Displays running processes and system resource usage.

27) ping google.com – Checks network connectivity.

28) ip addr – Displays network interface IP addresses.

29) man command_name – Displays the manual/help page for a command.
