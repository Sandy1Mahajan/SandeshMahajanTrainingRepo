# TrainingRepo
linux commands are used to interact with the operationg systemthrough the command-line terminal.

pwd - Displays the current working directory

ls - Lists files and directories.

ls -l -Displays files with detailed information.

ls -a -displays all files with the hidden files.

cd folder_name -changes the current directory.

cd .. Moves to parent directory.

cd ~ -Moves to the home directory.

touch file.text -creates an empty file.

mkdir folder -creates a new directory

rmdir folder - removes an empty directory.

cp file1 file2 -copies a file.

cat file.txt -Displays file contents.

grep - Searches for files and directories

sudo -Executes commands with elevated privilages.

mv old.txt new.txt - Moves or renames files and directories.

ps -Displays information about running processes.

Github Commands 

git --version -Displays the installed version.

git config - Configures your Git username and email.

git init -Initialize a new git repository.

git clone -Downloads an existing repository from GitHub.

git status - Displays the current repository status and changed files.

git add - Adds files to the staging area.

git commit -Saves staged changes.

git push -Uploads local commits to the remote Github repository.

git pull -Downloads  and integrates changes from the remote repository.

git fetch -Downloads changes from the remote repository without integrating then into your current branch.

git branch - Displays existing branch or creates new branch.
