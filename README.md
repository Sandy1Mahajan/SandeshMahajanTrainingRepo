# TrainingRepo
linux commands are used to interact with the operationg systemthrough the command-line terminal.

1. pwd - Displays the current working directory

2. ls - Lists files and directories.

3. ls -l -Displays files with detailed information.

4. ls -a -displays all files with the hidden files.

5. cd folder_name -changes the current directory.

6. cd .. -Moves to parent directory.

7. cd ~ -Moves to the home directory.

8. touch file.text -creates an empty file.

9. mkdir folder -creates a new directory

10. rmdir folder -removes an empty directory.

11. cp file1 file2 -copies a file.

12. cat file.txt -Displays file contents.

13. grep -Searches for files and directories

14. sudo -Executes commands with elevated privilages.

15. mv old.txt new.txt -Moves or renames files and directories.

16. ps -Displays information about running processes.

Github Commands 

1. git --version -Displays the installed version.

2. git config - Configures your Git username and email.

3. git init -Initialize a new git repository.

4. git clone -Downloads an existing repository from GitHub.

5. git status - Displays the current repository status and changed files.

6. git add - Adds files to the staging area.

7. git commit -Saves staged changes.

8. git push -Uploads local commits to the remote Github repository.

9. git pull -Downloads  and integrates changes from the remote repository.

10. git fetch -Downloads changes from the remote repository without integrating then into your current branch.

11.git branch - Displays existing branch or creates new branch.
