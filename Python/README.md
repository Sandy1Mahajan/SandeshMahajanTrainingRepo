## Python Variables

A variable is a named reference used to store data that can be accessed and manipulated in a program.

**Syntax:**

```python
variable_name = value
```

**Example:**

```python
name = "Sandesh"
age = 22
city = "Pune"
salary = 20000.00
is_developer = True

print(name)
print(age)
print(city)
print(salary)
print(is_developer)
```

**Output:**

```text
Sandesh
22
Pune
20000.0
True
```

## Python Data Types
A data type defines the type of value that a variable can hold.
Python is dynamically typed, meaning you do not need to explicitly declare a variable's type.

### A. Numeric Data Types
Python has three main numeric types.

1. Integer (int)

Stores whole numbers without decimal points.
**Example**
```python
age = 22
marks = 85

print(age)
print(marks)
print(type(age))
```

2. Float (float)
Stores decimal numbers.
**Example**
```python
salary = 25000.50
percentage = 85.75

print(salary)
print(percentage)
print(type(salary))
```
3. Complex (complex)

Stores numbers containing real and imaginary parts.
**Example**
```python
x = 2 + 3j

print(x)
print(x.real)
print(x.imag)
```
